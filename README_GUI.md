# PostalService — Desktop GUI (PySide6)

## Запуск в Windows

1. Установите Python 3.12 (если ещё не установлен).
2. Откройте PowerShell в папке проекта.
3. Установите зависимости:

   ```powershell
   py -m pip install -r requirements-gui.txt
   ```

4. Запустите графическое приложение:

   ```powershell
   py gui.py
   ```

   Или дважды щёлкните `run_gui.bat`.

## Возможности GUI

- Создание письма, бандероли или посылки через графическую форму.
- Выбор стандартной, экспресс- или экономичной доставки.
- Автоматический расчёт стоимости через существующий `DeliveryCalculator`.
- Сохранение результатов в SQLite (`data/postal_history.db`).
- Таблица истории расчётов.
- Экспорт истории в `postal_report.docx`.

## Важно

Графический интерфейс запускается непосредственно в Windows, а не внутри Docker.
Это позволяет использовать полноценное настольное окно PySide6 без настройки
передачи графического интерфейса из Linux-контейнера. Dockerfile и Compose
сохранены для выполнения требования лабораторной работы и запуска CLI в контейнере.
