# PostalService — расчёт стоимости почтовых отправлений

Учебный MVP-проект для лабораторной работы №2, вариант №6, уровень Well-done.

## Возможности
- Расчёт стоимости письма, бандероли и посылки.
- Учёт расстояния, фактического и объёмного веса, габаритов.
- Выбор экономичной, стандартной или экспресс-доставки.
- Сохранение истории расчётов в SQLite.
- Просмотр истории и экспорт в DOCX.
- Автоматические тесты pytest и запуск через Docker.

## Запуск локально
Требуется Python 3.10 или новее.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
python main.py
```

Для тестов:
```bash
pip install -r requirements-dev.txt
pytest -v
```

## Запуск в Docker
```bash
docker compose build
docker compose run --rm postal-service
```

Данные SQLite сохраняются в каталоге `data` на хосте.

## Краткая справка
1. Выберите пункт «Рассчитать стоимость».
2. Укажите вид отправления, отправителя и получателя.
3. Введите расстояние, вес и габариты в сантиметрах.
4. Выберите тип доставки.
5. Программа рассчитает цену и сохранит результат в SQLite.
6. Историю можно просмотреть в меню или выгрузить в DOCX.

## Модель тарификации
Это учебная тарифная модель, а не официальный тариф конкретного почтового оператора.

Объём:
`V = длина × ширина × высота` (см³)

Объёмный вес:
`Wоб = V / 5000` (кг)

Расчётный вес:
`Wр = max(Wфакт, Wоб)`

Базовая стоимость:
`C = Tкат + 0.12 × D + 35 × Wр + 0.002 × V`

Итог:
`Cитог = max(80, C) × Kдоставки`

Базовые тарифы категорий: письмо — 60 руб., бандероль — 90 руб., посылка — 140 руб.
Коэффициенты: экономичная — 0.8; стандартная — 1.0; экспресс — 1.8.
Сроки в учебной модели: 9, 5 и 2 дня соответственно.

Тарифы и коэффициенты вынесены в константы и могут быть изменены под условия преподавателя.
